# currency-converter

A simple and user-friendly Currency Converter web application that allows users to convert amounts between different currencies using JavaScript.

## Technologies

* HTML5
* CSS3
* JavaScript
* Currency Exchange API

## Features

* Convert currency from one currency to another
* Supports multiple currencies
* Simple and clean user interface
* Real-time currency conversion
* Easy-to-use input and currency selection
* Responsive design

## Project Files

* `index.html` — Main HTML structure
* `currency_converter.css` — Styling for the application
* `currency_converter.js` — Currency conversion functionality
* `codes.js` — Currency codes and related data

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select the currencies and enter an amount to convert.
